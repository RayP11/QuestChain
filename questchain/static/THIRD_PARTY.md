# Markdown rendering

`markdown-it.min.js` is the unmodified browser UMD build of **markdown-it 15.0.2**,
distributed under the MIT license in `markdown-it.LICENSE.txt`.

- Project: https://github.com/markdown-it/markdown-it
- Package: https://registry.npmjs.org/markdown-it/-/markdown-it-15.0.2.tgz
- Source within package: `package/dist/browser/markdown-it.umd.min.js`
- SHA-256: `635972b985228e8af9f0143647c68616b7a3bb09f6946e7e4a52e43dcf5e7be5`

The parser is bundled with the Python package and served locally. No CDN or
JavaScript build step is required. Chat disables raw HTML, rejects unsafe link
schemes, and displays image references as links instead of fetching them.
